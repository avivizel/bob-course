Skills ו-Subagents

שיטות חוזרות — שליטה

מטרת הפרק

בסוף הפרק: שיטות חוזרות — שליטה

מבוא

Skills = playbooks ל-Bob. Subagents = delegation — parent keeps accountability.

מושגי מפתח

רחפו מעל שם המושג (או לחצו במסך מגע) לפירוט: מבוא, משמעות וכוונה.

Skill

מבוא

אותה משימת review בפעם השלישית ראויה לפלייבוק. Skill הוא הפלייבוק.

משמעות

קובץ הוראות לשימוש חוזר: צ'קליסט, פורמט פלט, תנאי עצירה.

כוונה

הכוונה: ליצור skill אחרי שלוש חזרות, לא מאה קבצים מראש (skill bloat).

reusable instruction file.

דוגמה: SKILL: code-review.md
זהירות: skill bloat.

Subagent

מבוא

אפשר לפצל חקירה לסוכן משנה, אבל האחריות נשארת אצל ההורה.

משמעות

סוכן עם משימה צרה (למשל סריקת קוד) שמחזיר ממצאים, לא merge עצמאי.

כוונה

הכוונה: להגביל scope. Subagent בלי גבול הוא Agent שני בלי פיקוח.

task-specific agent.

דוגמה: explore codebase
זהירות: unbounded subagent.

Orchestration

מבוא

כמה סוכנים בלי מנצח מייצרים כאוס. Orchestration הוא התיאום.

משמעות

הסוכן הראשי מחלק משימות, אוסף פלט, ומחליט מה להציג לאדם.

כוונה

הכוונה: לא לבטוח עיוור בפלט subagent. ההורה (ואתם) בודקים.

parent coordinates.

דוגמה: main reviews sub output
זהירות: blind trust.

Handoff

מבוא

הנה סיכום מעורפל לא ניתן לביקורת. Handoff הוא פלט מובנה.

משמעות

מסירה בפורמט קבוע: רשימת ממצאים, קבצים, חומרה, המלצה.

כוונה

הכוונה: לדרוש מבנה. בלי מבנה אי אפשר לאשר או לדחות.

structured output.

דוגמה: findings list
זהירות: vague summary.
משל מהעולם האמיתי

Skill שמוגדרת פעם אחת רצה עקבית — בלי שינויים בין sessions. Task חוזרת שמתוארת בprompt חדש בכל פעם מקבלת פלטים שונים תלוי בניסוח. Subagent שמדווח ממצאים לparent שמאשר — מבדיל בין automation לאוטונומיה בלתי נשלטת.

שאלות לחשיבה: כתבו SKILL.md ל-TaskFlow PR review: רשמו 5 פריטי checklist, את ה-output format הנדרש, ומה ה-stop rule (מתי Skill לא ממשיכה בלי אישור).

עבודה עם IBM Bob
Plan

Define skill when 3+ repeats.

Prompt לדוגמה

Draft SKILL.md for TaskFlow code review: checklist, output format, stop rules.

למה זה עובד: Repeatable quality.

טעות נפוצה

לא: subagent auto-merge.

כן: subagent report → human approve.

מעבדה מודרכת
  1. Identify repeat task.
  2. Write skill.
  3. Run once.
  4. Refine.
  5. Commit skill.
  6. הצלחה = skill.md ב-repo, רץ עקבי בשתי הרצות עם אותו output format.

תרגיל עצמאי

Subagent scope — 3 allowed, 3 denied.

בדקו את עצמכם
Skill vs rule?
תשובה לדוגמה: skill = task playbook; rule = always on.
Subagent?
תשובה לדוגמה: delegate — parent accountable.
Handoff?
תשובה לדוגמה: structured — reviewable.

סיכום

  • Skills for repeats.
  • Subagents bounded.
  • Parent reviews.
  • Handoff structured.
