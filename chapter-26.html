Secure by Design עם Bob

אבטחה מהתכנון

מטרת הפרק

בסוף הפרק: אבטחה מהתכנון

מבוא

Security = requirements. OWASP basics: injection, auth, secrets, headers.

מושגי מפתח

רחפו מעל שם המושג (או לחצו במסך מגע) לפירוט: מבוא, משמעות וכוונה.

Input Validation

מבוא

כל קלט הוא חשוד עד שהוכח אחרת — כולל JSON ופרמטרים ב-URL.

משמעות

ניקוי ובדיקה בשרת: אורך, תווים, טיפוס, לפני שימוש ב-DB או במודל.

כוונה

הכוונה: לא לסמוך על הלקוח. Frontend הוא הצעה, לא חוק.

all inputs.

דוגמה: sanitize title
זהירות: trust client.

Secrets Management

מבוא

מפתח ב-git נשאר בהיסטוריה גם אחרי מחיקה מהקובץ.

משמעות

שמירת סודות ב-.env / vault, gitignore, וסריקה נגד commit בטעות.

כוונה

הכוונה: אם דלף — לסובב מיד, לא רק למחוק שורה.

.env, vault.

דוגמה: API_KEY env
זהירות: git commit.

Headers

מבוא

דפדפן בלי מדיניות אבטחה חשוף ל-XSS ולחיבור לא מוצפן.

משמעות

כותרות כמו CSP ו-HSTS (למשל דרך helmet) שמצמצמות התקפות נפוצות.

כוונה

הכוונה: לא להשאיר defaults ריקים ב-production. זה חלק מ-secure by design.

CSP, HSTS.

דוגמה: helmet.js
זהירות: default none.

Threat Model

מבוא

אבטחה בסוף הפרויקט היא יקרה. Threat model שואל מי תוקף מה מראש.

משמעות

רשימת נכסים, איומים והגנות: למשל גישה למשימה לפי ID של אחר.

כוונה

הכוונה: לכתוב איום לכל פיצ'ר ב-Plan, לא לחכות לאודיט חיצוני.

who attacks what.

דוגמה: IDOR on /tasks/:id
זהירות: no threats.
משל מהעולם האמיתי

אבטחה שנוספת בסוף הפרויקט מחייבת refactor — headers, validation ו-secrets management שלא תוכננו מראש. Threat model שנכתב ב-PRD הופך כל feature request לשאלת אבטחה: מה התוקף יכול לעשות עם זה? — לפני שכותבים שורה.

שאלות לחשיבה: זהו את ה-Threat #1 של TaskFlow בהגדרת STRIDE: כתבו Asset, Threat ו-Mitigation אחת. בדקו שה-Mitigation מיושמת כבר בקוד.

עבודה עם IBM Bob
Ask

Threat model before feature.

Prompt לדוגמה

Threat model TaskFlow: assets, threats, mitigations. STRIDE lite. No code.

למה זה עובד: Design security.

טעות נפוצה

לא: security audit at end only.

כן: threat per feature.

מעבדה מודרכת
  1. Threat model.
  2. Fix 1 finding.
  3. Secret scan.
  4. Header check.
  5. Document.
  6. הצלחה = threat model עם STRIDE lite, לפחות finding אחת תוקנה, secret scan נקי, CSP header פעיל.
