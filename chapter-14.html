Agent מהיר — איטרציות קצרות: שינוי → test → diff → stop או continue.

פרויקט Capstone — TaskFlow

ממשו שלב 1 מ-plan/create-task.md בלבד.

מושגי מפתח

רחפו מעל שם המושג (או לחצו במסך מגע) לפירוט: מבוא, משמעות וכוונה.

Iteration

מבוא

Agent מהיר מדי אם נותנים לו את כל התוכנית. איטרציה היא מנה קטנה.

משמעות

מחזור קצר: שינוי → הרצה → בדיקה → החלטה (המשך או עצירה).

כוונה

הכוונה: לממש שלב אחד מ-plan, לא את כל הקובץ בבת אחת.

change → run → verify.

דוגמה: step 1 only
זהירות: all steps auto.

Todo List

מבוא

עבודה סמויה מייצרת הפתעות. Todo גלוי מראה מה Bob עושה עכשיו.

משמעות

רשימת צעדים מעודכנת במהלך המשימה, שניתן לראות ולאשר.

כוונה

הכוונה: לדרוש רשימה גלויה. אם אין todos — קשה לדעת מה עוד ישתנה.

צעדים גלויים.

דוגמה: Bob todos
זהירות: hidden work.

Inline Instruction

מבוא

לפעמים השינוי צריך לחיות ליד השורה, לא בשיחה כללית.

משמעות

הערה ממוקדת בקובץ (למשל TODO ברור) שמגבילה את Bob למקום מדויק.

כוונה

הכוונה: להשתמש כשצריך תיקון נקודתי, לא כתחליף ל-Plan של פיצ'ר.

הערה בקובץ לשינוי ממוקד.

דוגמה: // TODO: add validation
זהירות: vague TODO.

Stop Condition

מבוא

בלי תנאי עצירה Agent ממשיך לתקן לנצח אחרי כישלון בדיקה.

משמעות

כלל מתי לעצור: טסט נכשל, חריגת scope, Diff לא מובן, חוסר הקשר.

כוונה

הכוונה: לעצור, לאבחן, ורק אז לתכנן תיקון — לא לולאת נחושים.

מתי עוצרים.

דוגמה: test fail → stop
זהירות: fix loop forever.
משל מהעולם האמיתי

כל iteration מסתיים בשתי שאלות: האם ה-test עבר? האם ה-diff מובן? אם התשובה לאחת מהן לא — עוצרים. Agent שממשיך על כשלון בנה שכבות על שגיאה; כל iteration נוסף מרחיק את נקודת החזרה.

שאלות לחשיבה: כתבו 3 stop conditions ספציפיות ל-TaskFlow Agent: מה יגרום לכם לעצור, לבדוק ולהחליט — לפני שממשיכים לשלב הבא.

עבודה עם IBM Bob
Agent

שלב אחד → tests → diff → decision.

Prompt לדוגמה

Implement step 1 only from @plan/create-task.md. Run tests. Show diff. Stop.

למה זה עובד: Bounded iteration.

טעות נפוצה

לא: Agent continues after test fail.

כן: Stop → diagnose → new plan.

מעבדה מודרכת
  1. Step 1 Agent.
  2. Run tests.
  3. Review diff.
  4. Approve or rollback.
  5. Document.
  6. הצלחה = שלב 1 מ-plan/create-task.md ממומש, tests ירוקים, diff מובן ומאושר.

תרגיל עצמאי

Stop condition — 3 triggers.

בדקו את עצמכם
שינוי קטן?
תשובה לדוגמה: קל diff, test, rollback.
Inline instruction?
תשובה לדוגמה: Scope ממוקד בקובץ.
Stop condition?
תשובה לדוגמה: test fail, scope creep, unclear diff.

סיכום

  • שלב אחד.
  • Test every iteration.
  • Stop > guess.
  • Diff = gate.
