# bob-course

Static course website for IBM Bob, published as a Hebrew RTL learning guide with 34 chapters and a generated index page.

## Live site

[https://avivizel.github.io/bob-course/](https://avivizel.github.io/bob-course/)

## What this repository contains

This repository contains a fully generated static website and the source data used to build it.

- 34 course chapters
- 1 landing page
- Hebrew right-to-left layout
- Vanilla HTML, CSS, and JavaScript
- Source-driven generation from files in [`scripts/`](scripts)

## Project structure

- [`scripts/chapters-part1.mjs`](scripts/chapters-part1.mjs) — chapter content for chapters 1–10
- [`scripts/chapters-part2.mjs`](scripts/chapters-part2.mjs) — chapter content for chapters 11–34
- [`scripts/concept-details.mjs`](scripts/concept-details.mjs) — extra concept popup content
- [`scripts/build.mjs`](scripts/build.mjs) — generates the static site
- [`assets/css/guide.css`](assets/css/guide.css) — site styling
- [`assets/js/guide.js`](assets/js/guide.js) — client-side interactions
- [`index.html`](index.html) — generated homepage
- [`chapter-01.html`](chapter-01.html) to [`chapter-34.html`](chapter-34.html) — generated chapter pages

## Important editing rule

Do **not** edit generated HTML files directly.

The root HTML files are regenerated by [`scripts/build.mjs`](scripts/build.mjs). To change the course, update the source files in [`scripts/`](scripts) and rebuild the site.

## Build the site

This project uses a simple Node-based build script.

```bash
node scripts/build.mjs
```

Running this command regenerates:

- [`index.html`](index.html)
- [`chapter-01.html`](chapter-01.html) through [`chapter-34.html`](chapter-34.html)

## Publishing

The site is intended to be served as a static website through GitHub Pages.

Live URL:
[https://avivizel.github.io/bob-course/](https://avivizel.github.io/bob-course/)

## Notes

- The site is RTL and optimized for Hebrew content.
- Course content is maintained in structured `.mjs` files.
- The build output is static and does not require a backend server to run.
