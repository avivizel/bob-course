Model API = שירות חיצוני. Timeout, retry, cost limits, fallbacks.

פרויקט Capstone — TaskFlow

TaskFlow: הצע כותרת משימה — optional AI assist.

מושגי מפתח

רחפו מעל שם המושג (או לחצו במסך מגע) לפירוט: מבוא, משמעות וכוונה.

Prompt Template

מבוא

קריאה חופשית למודל בכל פעם מייצרת פלט לא יציב. תבנית מייצבת.

משמעות

מבנה קבוע: הוראת מערכת + משתני משתמש כמו {{ctx}}, בלי להדביק קלט גולמי להוראת מערכת.

כוונה

הכוונה: לשלוט בגבולות המודל. קלט משתמש ב-system prompt הוא סיכון.

system + user pattern.

דוגמה: Suggest task title for: {{ctx}}
זהירות: raw user in system.

Token Budget

מבוא

מודל מתומחר לפי טokens. בלי תקרה העלות והזמן בורחים.

משמעות

הגבלת אורך קלט ופלט (למשל 500 tokens) לכל קריאה.

כוונה

הכוונה: לשים מקסימום בכל wrapper. בלי הגבלה אינו מקצועי.

max input/output.

דוגמה: 500 tokens
זהירות: unbounded.

Timeout/Retry

מבוא

שירות חיצוני נתקע. בלי timeout המשתמש מחכה לנצח.

משמעות

זמן מקסימום לקריאה, ומספר ניסיונות חוזרים מוגבל כשיש כשל רגעי.

כוונה

הכוונה: לעצב כשל: 3 שניות, ניסיון אחד, ואז fallback — לא hang.

fail gracefully.

דוגמה: 3s timeout, 1 retry
זהירות: hang forever.

Fallback

מבוא

AI הוא רשות, לא עמוד השדרה. כשהמודל נכשל המוצר עדיין חייב לעבוד.

משמעות

התנהגות חלופית: השארת שדה ריק, הודעה עדינה, או ערך ברירת מחדל — לא 500 למשתמש.

כוונה

הכוונה: לתכנן UX לכישלון לפני שמחברים מפתח API.

when model fails.

דוגמה: empty suggestion
זהירות: 500 to user.
משל מהעולם האמיתי

קריאה סינכרונית למודל AI ללא timeout חוסמת את כל ה-request עד לתשובה — אם המודל איטי, המשתמש תקוע. Fallback ברור (הצעה ריקה, הודעת שגיאה ידידותית) מבדיל בין תכונה שנכשלת בחן לבין שירות שמתרסק.

שאלות לחשיבה: תכננו את ה-fallback של הצעת כותרת ב-TaskFlow: מה המשתמש רואה אם המודל לא עונה תוך 3 שניות? מה הוא רואה אם ה-API key חסר? רשמו שני תרחישים עם ה-UX המתאים.

עבודה עם IBM Bob
Plan

Design API wrapper.

Prompt לדוגמה

Plan AI suggest-title: interface, timeout, cost cap, fallback. No keys in code.

למה זה עובד: Resilience design.

טעות נפוצה

לא: sync call, no timeout.

כן: async + timeout + fallback UI.

מעבדה מודרכת
  1. Plan AI feature.
  2. Wrapper function.
  3. Mock test.
  4. Cost estimate.
  5. Document.
  6. הצלחה = wrapper מחזיר fallback תוך 3 שניות כשהמודל לא זמין, mock test עובר.

תרגיל עצמאי

Fallback UX — 2 options.

בדקו את עצמכם
Token budget?
תשובה לדוגמה: control cost + latency.
Timeout?
תשובה לדוגמה: user not stuck waiting.
Keys?
תשובה לדוגמה: env only — never commit.

סיכום

  • Wrapper layer.
  • Timeout + fallback.
  • Cost cap.
  • Mock tests.
