HTML, CSS וחוויית משתמש

מסך ברור, נגיש, רספונסיבי

מטרת הפרק

בסוף הפרק: מסך ברור, נגיש, רספונסיבי

מבוא

HTML = מבנה. CSS = עיצוב. UX = המשתמש מבין בלי manual.

פרויקט Capstone — TaskFlow

UI TaskFlow: רשימה, טופס הוספה, מצבי All/Open/Done.

מושגי מפתח

רחפו מעל שם המושג (או לחצו במסך מגע) לפירוט: מבוא, משמעות וכוונה.

Semantic HTML

מבוא

div על כל דבר נראה במסך אבל לא אומר למכונה מה זה. HTML סמנטי כן.

משמעות

שימוש באלמנטים עם משמעות: button, nav, main, form, label — לא div עם onclick.

כוונה

הכוונה: נגישות, מקלדת, וקוד ש-Bob וקורא אנושי מבינים בלי ניחוש.

main, nav, button.

דוגמה: <button> not <div onclick>
זהירות: div soup.

Accessibility

מבוא

מסך יפה שאי אפשר להפעיל במקלדת אינו מסך שלם.

משמעות

תוויות, ניגודיות, סדר פוקוס, aria במקום שצריך, טקסט חלופי.

כוונה

הכוונה: לבדוק מקלדת וקורא מסך כחלק מ-AC של UI, לא כתוספת בסוף.

labels, contrast, keyboard.

דוגמה: aria-label
זהירות: color only.

Responsive

מבוא

משתמשים מגיעים גם מטלפון. עיצוב לשולחן בלבד שובר את החוויה.

משמעות

פריסה שעובדת ברוחבים שונים: flex/grid, נקודות שבירה, לא גלילה אופקית מקרית.

כוונה

הכוונה: לכלול מובייל ב-AC של TaskFlow לפני שסוגרים את ה-slice.

mobile + desktop.

דוגמה: flex/grid
זהירות: desktop only.

Design Token

מבוא

צבעים אקראיים בכל קובץ יוצרים מראה לא מקצועי וקשה לתחזוקה.

משמעות

משתני עיצוב משותפים: צבע, ריווח, רדיוס, גופן — מקור אחד לאמת ויזואלית.

כוונה

הכוונה: לבקש מ-Bob להשתמש בטוקנים, לא בערכי px ו-hex חדשים בכל פעם.

צבעים/spacing עקביים.

דוגמה: --primary: #0f62fe
זהירות: random px.
משל מהעולם האמיתי

Semantic HTML ו-design tokens הם גם תיעוד: כשקוראים <button> מבינים שמדובר בפעולה; כשרואים var(--primary) מבינים שזה צבע המערכת. קוד שמשתמש ב-div ו-pixel מפוזרים מכריח את הקורא לנחש כוונה.

שאלות לחשיבה: פתחו את ה-UI של TaskFlow בדפדפן וסמנו 3 אלמנטים: האם כל אחד משתמש ב-Semantic HTML? האם CTA הראשי ברור ב-keyboard בלבד?

מה Bob יכול לעשות — ומה אתם חייבים להבין

Bob יכול:

  • לייצר markup
  • לכתוב CSS
  • לשפר responsive layout

האדם חייב להבין:

  • structure vs style
  • semantics
  • accessibility basics
  • מה קורה במסך לאחר השינוי

  <form id="add-task" aria-label="הוספת משימה">
    <input name="title" required>
    <button type="submit">הוסף</button>

  <ul id="task-list"></ul>
</main>

  4. Mobile width.
